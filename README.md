# MediPulse – Hospital Management System & Data Analytics Dashboard

## About the Project
MediPulse is a hospital management web application built using PHP and MySQL. It provides separate dashboards for different hospital departments and a Data Analyst dashboard for exploring hospital datasets.

## Modules
- Admin Dashboard
- Doctor Dashboard
- Nurse Dashboard
- Receptionist Dashboard
- Billing Staff Dashboard
- Pharmacist Dashboard
- Lab Technician Dashboard
- Data Analyst Dashboard

## Data Analytics Features
- CSV dataset analysis
- Interactive charts using Chart.js
- Data filtering and searching
- Data summaries and trend analysis
- CSV data export

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Chart.js
- CSV

## Project Structure
- `admin/` – Admin dashboard
- `doctor/` – Doctor dashboard
- `nurse/` – Nurse dashboard
- `receptionist/` – Receptionist dashboard
- `billing_staff/` – Billing dashboard
- `pharmacist/` – Pharmacy dashboard
- `lab_technician/` – Laboratory dashboard
- `data_analyst/` – Data analytics dashboard
- `database/` – SQL database schema
- `dataset/` – Hospital CSV datasets

## How to Run Locally
1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs\`.
3. Start Apache and MySQL.
4. Import `database/schema.sql` into phpMyAdmin.
5. Configure your database connection in `config.php`.
6. Open `http://localhost/medipulse/` in your browser.
